1. Introduction — premier programme
public class HelloWorld { public static void main(String[] args) { System.out.println("Hello World"); } } javac HelloWorld.java // compile : produit HelloWorld.class java HelloWorld // exécute sur la machine virtuelle

Fichiers

Le source porte l'extension .java. Le compilateur javac produit un fichier .class. Pour l'instant : une classe par fichier, et le fichier porte le nom de sa classe.

Machine virtuelle (JVM)

Le fichier .class contient du pseudo-code (bytecode), pas un exécutable natif. La JVM de chaque système l'interprète : le même programme tourne sur tous les OS disposant d'une JVM.

Édition de liens à l'exécution

Le lien entre les classes se fait pendant l'exécution. Si on modifie une seule classe, on recompile seulement ce fichier.

2. Variables
Règle clé : une variable se déclare avant d'être utilisée, à l'intérieur du bloc main (ou d'une méthode).
int a, b; // déclaration a = 5; // affectation int v = 5; // déclaration + initialisation b = a + 1; // addition int q = 7 / 2; // quotient entier : 3 int r = 7 % 2; // reste : 1
Saisie et affichage
import java.util.Scanner; Scanner sc = new Scanner(System.in); int i = sc.nextInt(); // attend une saisie puis valide par Entrée float f = sc.nextFloat(); // le même Scanner sert pour plusieurs saisies String s = sc.next(); // chaîne sans préciser de type sc.close(); System.out.println("la valeur de i est " + i + ".");
Types numériques et caractères
Type Taille Valeurs
byte 1 octet −128 à 127
short 2 octets −32 768 à 32 767
int 4 octets −2³¹ à 2³¹ − 1
long 8 octets −2⁶³ à 2⁶³ − 1
float 4 octets réels (suffixe f : 3.14f)
double 8 octets réels, plus précis que float
char 2 octets un caractère Unicode : 'B'
Piège : un entier qui dépasse sa capacité « déborde ». Avec un byte, 127 + 1 vaut -128. Les flottants ne donnent qu'une valeur approchée.

3. Opérateurs

Arité

Unaire (-x, ~x, ++i), binaire (a + b), et un seul ternaire en Java (? :).

Associativité

Les binaires sont associatifs à gauche : a - b - c = (a - b) - c. Le = est associatif à droite : a = b = c donne d'abord b = c, puis a = b.

Priorités (de la plus forte à la plus faible)
Niveau Opérateurs
1unaires : - ~ ++ --
2produit : * / %
3somme : + -
4décalage : << >>
5ET binaire : &
6OU exclusif : ^
7OU binaire : |
8affectation : =
Opérations sur les bits
60 & 15 = 12 // 0011 1100 ET 0000 1111 = 0000 1100 60 | 15 = 63 // OU : 0011 1111 60 ^ 15 = 51 // OU exclusif : 0011 0011 32 << 2 = 128 // décalage à gauche : 0010 0000 -> 1000 0000 32 >> 3 = 4 // décalage à droite : 0010 0000 -> 0000 0100
Formes contractées et ordre d'évaluation
a += b; // équivalent à a = a + b (idem -=, *=, /=, %=, &=, |=, ^=, <<=, >>=) a = 1; b = (a++) + a; // a++ vaut 1 puis a = 2 : b = 1 + 2 = 3 a = 1; b = (++a) + a; // ++a incrémente d'abord : b = 2 + 2 = 4
Réflexe : les formes contractées (++, --) ne sont sûres que si l'ordre d'évaluation ne change pas le résultat. Dans le doute, ne les mélangez pas dans une même expression.
Conversions de types

Dans un calcul mixte, le type le plus « large » l'emporte : double > float > long > int > short > byte. La conversion vers un type plus petit doit être explicite (cast) et peut faire perdre de l'information : (byte) 200 vaut -56.

4. Objets et classes
public class Point { float abscisse; float ordonnee; void presenteToi() { System.out.println("Je suis un point (" + abscisse + ", " + ordonnee + ")"); } public static void main(String[] args) { Point p; // p ne contient pas encore d'objet (null) p = new Point(); // instanciation : allocation d'un objet p.abscisse = 1; p.ordonnee = 2; p.presenteToi(); // appel de méthode sur l'objet p } }

Classe = type construit

Une classe regroupe des champs (attributs) et des méthodes. Une variable de type classe est une référence vers un objet.

new

Crée un objet et renvoie sa référence. Une référence non initialisée vaut null : le compilateur signale « might not have been initialized ».

this et ramasse-miettes

this désigne l'objet courant dans une méthode. Pas de free() : le Garbage Collector supprime les objets qui ne sont plus référencés.

Packages : une classe d'une bibliothèque s'utilise après un import en début de fichier (import java.util.ArrayList;).

5. Encapsulation
Idée centrale : on cache les détails de l'implémentation. Les champs sont private, et seules les méthodes public forment l'interface de la classe.
Visibilité Qui peut utiliser l'élément ?
publicTout le monde.
privateSeulement la classe elle-même (seule l'instance propriétaire).
protectedLa classe et ses classes dérivées.
(aucun mot-clé)Visibilité par défaut : limitée au package.
Accesseurs, constructeurs, surcharge
public class Compteur { private int valeur; // constructeur : même nom que la classe, pas de type de retour, // appelé automatiquement à chaque new public Compteur(int depart) { valeur = depart; } // constructeur surchargé (même nom, paramètres différents) public Compteur() { this(0); } // accesseurs : getX et setX pour un attribut privé X public int getValeur() { return valeur; } public void setValeur(int v) { valeur = v; } }

Accesseurs

Pour un attribut privé X : getX() lit, setX() écrit. L'utilisateur passe par les méthodes, jamais par le champ.

Constructeur

Initialise l'objet dès sa création, ce qui évite d'oublier une méthode d'initialisation. Il peut recevoir des paramètres.

Surcharge

Plusieurs méthodes (ou constructeurs) de même nom, avec des paramètres différents. Le compilateur choisit selon les arguments.

Exemple : une file circulaire

Le cours construit une file de nombres entiers dans un tableau int[] entiers, avec deux indices first (tête) et firstFree (première place libre), et des méthodes enfile, defile, premier, estVide, estPlein. Le principe à retenir : tout l'état est private, et la file ne s'utilise que par ses méthodes.

Collections et types paramétrés
import java.util.ArrayList; ArrayList<Integer> notes = new ArrayList<Integer>(); notes.add(12); // ajoute à la fin int premiere = notes.get(0); // lit l'élément d'indice 0 (pas de cast) System.out.println(notes.size()); for (int valeur : notes) // parcours : for (T x : collection) System.out.println(valeur);
Intérêt : ArrayList<Integer> s'agrandit seul et le type paramétré évite les casts laids ((int) a.get(i) sur une liste non typée).

6. Exceptions
Pourquoi : séparer le traitement des erreurs du reste du code, forcer à gérer les erreurs prévisibles, et rattraper une erreur pendant l'exécution au lieu de planter.
try { int[] t = new int[3]; t[5] = 1; // lève ArrayIndexOutOfBoundsException } catch (ArrayIndexOutOfBoundsException e) { System.out.println("Indice invalide"); } finally { System.out.println("Toujours exécuté"); // ex. fermer un fichier }

try / catch

Le code à risque va dans le try. Si une exception est levée, le reste du try est interrompu et le catch correspondant s'exécute.

throws et propagation

Une méthode qui peut lever une exception le déclare dans son en-tête (throws). L'appelant la traite, ou la propage à son tour. Une exception non rattrapée remonte jusqu'à la JVM.

Définir et lever

Une exception est une classe qui hérite de Exception. On la lève avec throw new MonException(...).

Plusieurs catch et RuntimeException
Cas Obligation
RuntimeException et ses sous-classes (ex. ArrayIndexOutOfBoundsException)Non contrôlée : le code compile sans la traiter.
Exception « classique » (hérite de Exception sans passer par RuntimeException)Contrôlée : elle doit être rattrapée ou déclarée avec throws.
Ordre des catch : placez les exceptions les plus précises d'abord. catch (Exception e) en dernier attrape tout le reste.
