Syntaxe générale du mémento
SELECT [DISTINCT] expressions FROM tables WHERE prédicat GROUP BY expressions HAVING prédicat ORDER BY expressions [ASC | DESC];
Restrictions
Forme Utilisation
=, <>, <, >, <=, >= Comparaisons.
BETWEEN ... AND ... Intervalle.
[NOT] LIKE Recherche sur une chaîne.
[NOT] IN (...) Appartenance à une liste ou à une sous-requête.
IS [NOT] NULL Tester une valeur absente ou présente.
AND / OR Combiner plusieurs prédicats.
Jointure
SELECT expr1, expr2, ... FROM table1, table2 WHERE table1.champ1 = table2.champ2;

Exercices EQUUS à savoir traduire en SQL

Bloc 1 — Structure & LMD

  • Créer la table CHEVAL avec une clé primaire.

  • Augmenter de 35 kg le poids de « Belle de jour ».

Bloc 2 — Interrogation

  • Propriétaires de Bordeaux triés par nom et prénom.
  • Compter les chevaux mâles « pur sang ».
  • Calculer la durée totale des reprises d'octobre 2012.
  • Afficher les différents moniteurs des reprises 15, 16 et 17.
  • Afficher les chevaux par âge décroissant.

Bloc 3 — MySQL

  • Créer la base EQUUS.
  • Afficher les bases créées.
  • Se connecter à EQUUS.
