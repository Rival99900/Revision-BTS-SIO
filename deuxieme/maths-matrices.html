2.1 — Définition d’une matrice

Matrice n × p

Une matrice de dimension n × p est un tableau rectangulaire composé de n lignes et p colonnes. Le coefficient situé à la ligne i et à la colonne j se note aᵢⱼ.

Cas particuliers

  • p = 1 : matrice colonne.
  • n = 1 : matrice ligne.
  • n = p : matrice carrée d’ordre n.
Exemples vérifiés

A ∈ M₃₂, aᵢⱼ = i / j

A = ⎛ 1 1/2 ⎞ ⎜ 2 1 ⎟ ⎝ 3 3/2 ⎠

B ∈ M₃₂, bᵢⱼ = (i − j)²

B = ⎛ 0 1 ⎞ ⎜ 1 0 ⎟ ⎝ 4 1 ⎠

C ∈ M₂₂, cᵢⱼ = i + j − 1

C = ⎛ 1 2 ⎞ ⎝ 2 3 ⎠

Lecture d’un coefficient

Dans A, a₃₂ = 3/2 : troisième ligne, deuxième colonne.

2.2.1 — Addition
Condition : deux matrices peuvent être additionnées uniquement si elles ont exactement la même dimension.
A + B = ⎛ 1 3/2 ⎞ ⎜ 3 1 ⎟ ⎝ 7 5/2 ⎠

Commutativité

A + B = B + A

Associativité

(A + B) + C = A + (B + C)

Matrice nulle

A + Oₙₚ = A

Matrice opposée

A + (−A) = Oₙₚ

−A = ⎛ −1 −1/2 ⎞ ⎜ −2 −1 ⎟ ⎝ −3 −3/2 ⎠
2.2.2 — Multiplication par un réel

Pour un réel k, chaque coefficient de A est multiplié par k. La dimension ne change pas.

2A

⎛ 2 1 ⎞ ⎜ 4 2 ⎟ ⎝ 6 3 ⎠

−3B

⎛ 0 −3 ⎞ ⎜ −3 0 ⎟ ⎝−12 −3 ⎠
2.2.3 — Multiplication de deux matrices
Condition : si A est de dimension n × m et B de dimension m × p, alors A × B existe et sa dimension est n × p.
αᵢⱼ = Σₖ₌₁ᵐ aᵢₖ × bₖⱼ
  • La multiplication matricielle n’est généralement pas commutative : A × B ≠ B × A.
  • Elle est associative : (A × B) × C = A × (B × C).
  • Elle est distributive par rapport à l’addition.
A × C = ⎛ 2 7/2 ⎞ ⎜ 4 7 ⎟ ⎝ 6 21/2 ⎠

Exercice 5 — existence des produits

A ∈ M₁₃ et B ∈ M₃₂.

  • A × B existe : 3 colonnes pour A et 3 lignes pour B. Le résultat appartient à M₁₂.
  • B × A n’existe pas : B possède 2 colonnes alors que A possède 1 ligne.

Exercice 11 — matrice carrée telle que A² = O₂

Pour A = ((a, b), (c, d)), on obtient :

A² = ⎛ a² + bc b(a + d) ⎞ ⎝ c(a + d) bc + d² ⎠

Pour obtenir O₂ avec des coefficients entiers non nuls, on peut imposer a + d = 0 et a² + bc = 0.

Choix : a = 1, d = −1, b = 1, c = −1 A = ⎛ 1 1 ⎞ ⎝ −1 −1 ⎠ A² = O₂
À retenir : avant de multiplier deux matrices, vérifiez toujours « colonnes de la première = lignes de la seconde ».
