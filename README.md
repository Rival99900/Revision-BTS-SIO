# BTS SIO — Site de révision 1re et 2e année

Ouvrez `index.html` dans un navigateur pour démarrer le site. Aucune installation n’est nécessaire.

## Contenu

- `premiere/` : fiches de révision de 1re année.
- `premiere/sql.html` : SQL et bases de données de 1re année, consolidés uniquement à partir des supports SLAM et SISR du Drive.
- `premiere/cejm/` : 11 fiches CEJM détaillées.
- `deuxieme/cejm-droit-numerique.html` : CEJM Droit — impact du numérique.
- `deuxieme/sql-revision.html` : révision SQL de 2e année à partir du mémento SIO2 et de l’exercice EQUUS présents dans le Drive SLAM.
- `quiz.html` : quiz général, filtrable par année, matière et type de question.

## Base de données / SQL

La partie SQL couvre les notions présentes dans les supports : `SELECT`, `FROM`, `WHERE`, `DISTINCT`, `ORDER BY`, `IN`, `NOT IN`, `BETWEEN`, `LIKE`, `NULL`, jointures, fonctions `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, `HAVING`, LMD (`INSERT`, `UPDATE`, `DELETE`), LDD (`CREATE`, `ALTER`, `DROP`, contraintes, vues) et commandes MySQL vues dans les TP.

Les contenus de 2e année ne sont ajoutés que lorsqu’un support correspondant existe dans le Drive. Aucun chapitre absent des sources n’est complété artificiellement.

## Diffusion en classe

La rédaction du site utilise le vouvoiement. Les formulations ont été harmonisées et relues pour une utilisation collective en classe.
