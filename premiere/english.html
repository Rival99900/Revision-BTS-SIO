LES TEMPS
Les 6 temps essentiels en anglais
1. Present Simple — État permanent / habitude
🔧 Forme : Sujet + verbe (+ s à la 3e pers. sing.)
✅ Utilisation : faits généraux, habitudes, vérités, documentations techniques
💬 Exemples IT :
"The server stores all user data." (Le serveur stocke toutes les données)
"PHP processes requests on the server side."
"The algorithm runs in O(n²) time."
2. Present Continuous — Action en cours maintenant
🔧 Forme : Sujet + am/is/are + verbe-ING
✅ Utilisation : action en cours au moment où l'on parle, évolutions temporaires
💬 Exemples IT :
"The system is running a full scan." (en ce moment)
"We are currently deploying the new version."
"The database is being updated."
3. Past Simple — Action passée et terminée
🔧 Forme : Sujet + verbe au passé (+ -ed ou irrégulier)
✅ Utilisation : événement passé à un moment précis, rapport d'incident
💬 Exemples IT :
"The server crashed at 3:00 AM."
"The developer fixed the bug yesterday."
"We deployed the patch last Tuesday."
4. Present Perfect — Action passée, résultat présent
🔧 Forme : Sujet + have/has + participe passé
✅ Utilisation : action passée dont le résultat est encore présent, expérience
💬 Exemples IT :
"The team has released a new update." (elle vient de sortir)
"I have configured the firewall." (c'est maintenant configuré)
"The database has been compromised."
5. Future Will — Décision spontanée / prédiction
🔧 Forme : Sujet + will + infinitif
✅ Utilisation : décision prise au moment de parler, prédiction, promesse
💬 Exemples IT :
"I will restart the server now." (décision immédiate)
"The system will automatically back up every night."
"This approach will improve performance."
6. Future Going to — Plan prévu à l'avance
🔧 Forme : Sujet + am/is/are going to + infinitif
✅ Utilisation : intention planifiée, évidence d'une situation future
💬 Exemples IT :
"We are going to migrate to the cloud next month."
"She is going to present the project tomorrow."
"The server is going to crash — the CPU is at 100%!"

PHRASES TYPES

Our company specialises in... / Our company is specialised in...
Nous proposons des solutions de…
We provide / offer solutions for...
L'objectif principal du projet est de…
The main objective / goal of the project is to...
Ce projet a été développé par une équipe de…
This project was developed by a team of...
Décrire un système informatique
Le système est composé de…
The system consists of / is made up of...
Le serveur traite les requêtes des clients.
The server handles / processes client requests.
Les données sont stockées dans une base de données relationnelle.
The data is stored in a relational database.
L'application utilise un chiffrement AES-256.
The application uses AES-256 encryption.

The server is currently down / unavailable.
Nous avons identifié une faille de sécurité.
We have identified a security vulnerability / flaw.
Une violation de données a été détectée.
A data breach has been detected.
Le problème a été résolu à 14h.
The issue has been resolved / fixed at 2 PM.

EMAIL PRO
Structure d'un email professionnel en anglais
Partie
Formules courantes
Objet (Subject)
Court, précis : "Incident Report — Server Outage 31/03" / "Request for information"
Formule d'appel
Dear Mr/Ms [Nom], | Dear Sir/Madam, | Dear [Prénom], (informel)
Accroche
I am writing to... | Further to our meeting... | I hope this email finds you well.
Corps
Please find attached... | I would like to inform you that... | Could you please...?
Formule de clôture
Yours sincerely (nom connu) | Yours faithfully (nom inconnu) | Best regards,
Signature
[Prénom Nom] | [Titre / Poste] | [Entreprise] | [Téléphone]
⚠️ Règle d'or : Dear Mr Smith → Yours sincerely (nom connu). Dear Sir/Madam → Yours faithfully (nom inconnu).
Formules utiles par situation

Demander des informations

"Could you please send me…?"
"I would like to know…"
"Please let me know if…"
"Could you clarify…?"

Joindre un document

"Please find attached…"
"I am attaching the report…"
"Enclosed please find…"
"See attached document."

Signaler un incident

"I am writing to report…"
"We have identified an issue with…"
"The problem occurred at…"
"The issue has been resolved."

Remercier / Confirmer

"Thank you for your email."
"I confirm receipt of…"
"I would like to thank you for…"
"Please do not hesitate to contact me."

Exemple complet — Rapport d'incident
Subject: Incident Report — Database Server Outage — 31/03/2026 Dear Mr Johnson, I am writing to inform you of a security incident that occurred on our production server on 31 March 2026. At approximately 03:15 AM, our monitoring system detected unusual activity on the database server. The server became unavailable at 03:22 AM. Investigation revealed that the outage was caused by an attempted SQL injection attack. Our firewall successfully blocked the intrusion. However, the server was temporarily overloaded and required a restart. Actions taken: - The server was restarted at 04:05 AM. - All access logs have been reviewed. - Security patches have been applied. - Passwords have been reset as a precaution. The service was fully restored at 04:30 AM. No data was compromised. We are currently reviewing our security protocols to prevent future incidents. Please find attached the full incident report for your reference. Please do not hesitate to contact me if you require further information. Yours sincerely, Jean Dupont IT Security Officer — BTS SIO Tel: +33 6 12 34 56 78
