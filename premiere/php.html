VARIABLES & I/O
"

Un script PHP est délimité par <?php et ?> . Les instructions sont séparées par des points-virgules . Les variables commencent toujours par $ .

Variables & Affectation

Définition

  • Emplacement mémoire temporaire nommé
  • Une seule valeur à la fois
  • Nom commençant par $ : $a , $nom , $compteur
  • Affectation avec = : $a = 4;

Affichage

Utiliser print() ou echo :
print("Bonjour");
print($variable);
echo "Valeur : $a\n";

⚠️ Guillemets !

print('$toto') → affiche $toto (littéral)
print("$toto") → affiche la valeur de $toto

Les guillemets doubles interpolent les variables. Les guillemets simples sont littéraux.

fgets(STDIN) — Saisie clavier

Saisit une chaîne depuis l'entrée standard (inclut le \n de fin !)

$a = fgets(STDIN); // avec le \n $a = trim(fgets(STDIN)); // sans le \n ✅
Saisie de plusieurs variables
<?php // Méthode 1 : saisies séparées $a = trim(fgets(STDIN)); $b = trim(fgets(STDIN)); // Méthode 2 : saisie sur une ligne "10 20" $s = fgets(STDIN); list($a, $b) = explode(' ', trim($s)); // Si saisie : "10 20" → $a = "10", $b = "20" // Affichage print("la valeur $a a été saisie dans \$a\n"); print("Première: $a, Deuxième: $b\n"); ?>
TYPES & OPÉRATEURS
Les types en PHP

Types principaux

  • int Entier : $a = 3 , $a = -4
  • float Virgule flottante : $a = 3.14
  • string Chaîne : $a = "Bonjour"
  • bool Booléen : true / false
  • null Absence de valeur

Opérations entières

  • + Addition
  • - Soustraction
  • * Multiplication
  • / Division (renvoie un nombre décimal si nécessaire)
  • % Modulo (reste de la division)

Fonctions numériques utiles

intdiv($a, $b) — division entière
intdiv(7, 2) → 3

abs($a) — valeur absolue
round($a) — arrondi
floor($a) — arrondi vers le bas
ceil($a) — arrondi vers le haut

Exemple

$a = 1; $b = 2; $c = $a + $b; // 3 print($c); // affiche 3 print(intdiv(7, 2)); // → 3 print(7 % 2); // → 1 (reste)
Caractères & Code ASCII

ord() et chr()

ord('a') → code ASCII = 97
chr(97) → caractère = 'a'

chr(ord('a') + 1) → 'b'

Opérations sur caractères

$t = 'b'; // code ASCII 98 $t++; // code 99 = 'c'print("$t\n"); // affiche c // Boucle sur les lettres : for ($c = 'a'; $c <= 'z'; $c++) { print($c. " "); // a b c... z }

Manipulation de chaînes

Concaténation : opérateur . (point)
$a = "Bon". "jour";

strlen($s) → nombre de caractères
strtolower($s) → en minuscules
strtoupper($s) → en majuscules
trim($s) → supprime espaces/\n

Accès par indice

$s[$i] — lettre à l'indice $i (commence à 0)

$t = "Bonjour"; print($t[0]); // B print($t[6]); // r print(strlen($t)); // 7
CONDITIONS
Traitement conditionnel — if / else

Syntaxe if

if ($a > 1) { print('Supérieur à 1'); }

Syntaxe if / else

if ($a > 1) { print('Supérieur à 1'); } else { print('Inférieur ou égal à 1'); }

⚠️ Accolades optionnelles

Si une seule instruction, les accolades sont facultatives :

if ($a > 1) print('Sup à 1'); else print('Inf ou égal');

Elseif (sinon si)

if ($a > 10) { print("Grand"); } elseif ($a > 0) { print("Positif"); } else { print("Négatif ou zéro"); }
Opérateurs de comparaison
Opérateur Signification Exemple
== Égalité (valeur seulement) $a == 3
=== Égalité stricte (valeur + type) $a === 3
!= Différent $a != 3
> / < Inégalités strictes $a > 3
>= / <= Inégalités larges $a >= 3
⚠️ Attention ! Ne pas confondre = (affectation) avec == (comparaison). Erreur très fréquente !
Connecteurs logiques

ET logique : &&

Vraie si les deux conditions sont vraies.
$a==1 && $b==2

OU logique : ||

Vraie si au moins une condition est vraie.
$a==1 || $b==2

Négation : !

Inverse le résultat booléen.
!($a == 1) → vrai si $a ≠ 1

⚠️ Valeurs Falsy

PHP considère comme false :
0 · 0.0 · "" · "0" · null · [] · variable non définie

$age = 20; $argent = 50; $estMajeur = ($age >= 18); // true $aAssezArgent = ($argent >= 100); // false $peutEntrer = $estMajeur && $aAssezArgent; // false if ($peutEntrer) { print("Bienvenue au club !"); } else { print("Accès refusé."); } // Test valeur falsy : $nom = ""; if (!$nom) print("Erreur : nom vide !");
BOUCLES
Les 3 types de boucles PHP

While — TANT QUE

Continue tant que la condition est vraie. Peut ne jamais s'exécuter .

$count = 1; while ($count <= 5) { print($count. " "); $count++; } // Affiche : 1 2 3 4 5

Do-While — FAIRE … TANT QUE

S'exécute au minimum une fois , puis vérifie la condition.

do { print($count. " "); $count++; } while ($count <= 5); // Exécuté au moins 1 fois !

For — POUR

Quand on sait combien de fois itérer.

for ($i = 1; $i <= 5; $i++) { print($i. " "); } // Affiche : 1 2 3 4 5
Quand utiliser quelle boucle ?
Boucle Utiliser quand… Exemple typique
while Nombre d'itérations inconnu à l'avance, peut s'exécuter 0 fois Lire un fichier ligne par ligne
do-while Doit s'exécuter au moins 1 fois (menu, contrôle de saisie) Demander un MDP jusqu'à ce qu'il soit correct
for Nombre d'itérations connu (parcourir un tableau de n éléments) Afficher les éléments d'un tableau
// Exemple concret : contrôle de saisie avec do-while do { $age = intval(trim(fgets(STDIN))); if ($age < 0 || $age > 120) { print("Âge invalide, ressaissez !\n"); } } while ($age < 0 || $age > 120); print("Âge saisi : $age\n");
TABLEAUX & CHAÎNES
Les tableaux

Créer un tableau

$a = array(); // vide $a = [1, 2, 3]; // initialisé $a[] = $v; // ajouter à la fin

Accès aux éléments

Indices commencent à 0

$a[0]; $a[1]; $a[2]; // Taille : count($a) // Plage valide : 0 à count($a)-1

Taille et boucle for

$t = [10, 20, 30, 40]; for ($i = 0; $i < count($t); $i++) { print($t[$i]. "\n"); }

Ajout d'élément

$tableau[] = $valeur
Ajoute $valeur à la fin du tableau.

$noms = []; $noms[] = "Alice"; // index 0 $noms[] = "Bob"; // index 1 $noms[] = "Carla"; // index 2
Parcours avec foreach
// foreach avec clé et valeur : foreach ($tableau as $index => $valeur) { print("$index : $valeur\n"); } // foreach valeur seulement : foreach ($tableau as $valeur) { print($valeur. "\n"); }
Tableaux associatifs

Définition

L'indice peut être une chaîne de caractères (clé). Très utilisé pour représenter des "objets" simples.

Exemple

$etudiant = array(); $etudiant['nom'] = 'Alice'; $etudiant['prenom'] = 'Dupont'; $etudiant['note'] = 17.5; foreach ($etudiant as $cle => $val) { print("$cle => $val\n"); }

isset() — vérifier existence

isset($v) → vrai si $v existe et n'est pas null
isset($t[$cle]) → vrai si la clé est définie

if (isset($etudiant['note'])) { print("Note : ". $etudiant['note']); }
Fonctions utiles sur les chaînes

explode()

Subdivise une chaîne en tableau selon un séparateur.

$t = explode(',', "a,b,c,d"); // $t[0]="a" $t[1]="b" $t[2]="c" $t[3]="d" // Lire une ligne d'entiers séparés par espaces : $s = trim(fgets(STDIN)); $nums = explode(' ', $s);

var_dump()

Affiche le type et la valeur d'une variable. Outil de débogage essentiel.

var_dump($t); // array(4) { // [0]=> string(1) "a" // [1]=> string(1) "b"... // }

Autres fonctions

substr($s, $debut, $longueur) — sous-chaîne
strpos($s, $cherche) — position d'une sous-chaîne
str_replace($old, $new, $s) — remplacement
implode(',', $t) — tableau → chaîne
