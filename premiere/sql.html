Interrogation d'une base : SELECT
"

Une requête d'interrogation utilise SELECT , FROM et, si nécessaire, WHERE .

SELECT

Indique les colonnes à afficher. * permet de sélectionner toutes les colonnes.

FROM

Indique la ou les tables sur lesquelles la requête doit travailler.

WHERE

Ajoute une condition de sélection afin de ne conserver que les lignes qui respectent le prédicat.

SELECT colonne1, colonne2 FROM nom_table WHERE condition;
Projection, doublons et classement

DISTINCT

Supprime les lignes en double dans le résultat d'une projection.

SELECT DISTINCT Ville FROM CLIENT WHERE Cat = 'B2';

ORDER BY

Classe le résultat avec ASC ou DESC .

SELECT Nom, Salaire FROM Employes ORDER BY Salaire DESC;
Filtres vus dans les exercices
Opérateur / clause Rôle Exemple issu des notions travaillées
=, <>, <, >, <=, >= Comparer deux expressions. WHERE PrixH > 100
AND / OR Combiner plusieurs conditions. WHERE couleur='blanc'AND disponible=true
IN / NOT IN Tester l'appartenance ou la non-appartenance à une liste. WHERE Couleur IN ('bleu','blanc','rouge')
BETWEEN Tester un intervalle dont les bornes sont comprises. WHERE PrixH BETWEEN 100 AND 200
IS NULL / IS NOT NULL Tester l'absence ou la présence d'une valeur. WHERE PrixH IS NULL
LIKE Comparer avec une chaîne incomplète. WHERE Nomtype LIKE 'b%'
Caractères jokers : % représente une chaîne quelconque et _ représente un caractère quelconque.

Commence par b

WHERE Nomtype LIKE 'b%';

Finit par r

WHERE Nomtype LIKE '%r';
Relier plusieurs tables
"

Une jointure permet de répondre à des questions portant sur plusieurs tables. Le critère de jointure relie les champs correspondants.

Produit cartésien : si plusieurs tables sont placées dans FROM sans critère de jointure, toutes les combinaisons de lignes sont produites.
SELECT Numembarcation, Couleur, Nomtype FROM EMBARCATION, TYPEMBARCATION WHERE EMBARCATION.Codetype = TYPEMBARCATION.Codetype;
Jointure sur plusieurs tables
SELECT lc.Numlocation, Dateloc, emb.Numembarcation, Nomtype FROM EMBARCATION emb, TYPEMBARCATION t, LOUER lr, LOCATION lc WHERE emb.Codetype = t.Codetype AND lr.Numembarcation = emb.Numembarcation AND lr.Numlocation = lc.Numlocation ORDER BY emb.Numembarcation;

Clé primaire

Identifie de manière unique une ligne de la table.

Clé étrangère

Référence la clé d'une autre table et permet d'établir le lien relationnel utilisé par la jointure.

Fonctions de groupe

Cinq fonctions standard permettent de réaliser des calculs sur plusieurs lignes.

Fonction Rôle Exemple
COUNT() Compte des lignes ou des valeurs. SELECT COUNT(*) FROM embarcation;
SUM() Calcule une somme. SELECT SUM(salaire) FROM Employes;
AVG() Calcule une moyenne. SELECT AVG(PrixH) FROM TYPEMBARCATION;
MIN() Renvoie la plus petite valeur. SELECT MIN(PrixH) FROM TYPEMBARCATION;
MAX() Renvoie la plus grande valeur. SELECT MAX(PrixH) FROM TYPEMBARCATION;
GROUP BY et HAVING

GROUP BY

Regroupe les lignes selon une ou plusieurs expressions avant le calcul d'un agrégat.

SELECT couleur, COUNT(*) FROM embarcation GROUP BY couleur;

HAVING

Cette clause filtre les groupes après l'agrégation.

SELECT departement, AVG(salaire) FROM Employes GROUP BY departement HAVING AVG(salaire) > 3000;
LMD — Langage de Manipulation de Données
"

Le LMD regroupe les commandes permettant de sélectionner, insérer, modifier ou supprimer des données dans une base relationnelle.

SELECT

Sélectionner des données.

INSERT

Ajouter de nouveaux enregistrements.

UPDATE

Modifier des enregistrements existants.

DELETE

Supprimer des enregistrements.

INSERT INTO table (champ1, champ2,...) VALUES (val1, val2,...); UPDATE table SET champ1 = expr1, champ2 = expr2 WHERE prédicat; DELETE FROM table WHERE prédicat;
Point de vigilance : la clause WHERE est facultative pour UPDATE et DELETE . Il faut donc vérifier le prédicat avant d'exécuter une modification ou une suppression.
Insertion à partir d'une requête
INSERT INTO table (champ1, champ2,...) SELECT... FROM... WHERE...;
LDD — Langage de Définition de Données

Le LDD agit sur la structure de la base : tables, vues et contraintes. Les trois grandes familles sont CREATE , ALTER et DROP .

CREATE TABLE NomTable ( Colonne1 Type [Contraintes], Colonne2 Type [Contraintes],... );
Contraintes de champs
Contrainte Rôle
NOT NULL Le champ doit obligatoirement être renseigné.
UNIQUE Les valeurs doivent être différentes.
DEFAULT Définit une valeur par défaut.
CHECK Impose une condition sur les valeurs.
AUTO_INCREMENT Auto-incrémente un champ numérique.

Clé primaire

PRIMARY KEY (NumService)

Identifie chaque enregistrement.

Clé étrangère

FOREIGN KEY (NumServiceEmploye) REFERENCES service (NumService)

Assure la référence vers une autre table.

Intégrité référentielle : elle maintient la cohérence des relations entre clés étrangères et clés primaires.
Vues et suppression
CREATE VIEW nom_vue AS SELECT * FROM EMPLOYE WHERE nom_service = 'laboratoire'; DROP TABLE nom_table; DROP VIEW nom_vue; TRUNCATE TABLE nom_table;
TRUNCATE TABLE : les données sont supprimées mais la structure de la table est conservée.
Modification de structure
ALTER TABLE nom_table ADD COLUMN nom_champ Type_donnee; ALTER TABLE nom_table DROP COLUMN nom_champ; ALTER TABLE nom_table DROP CONSTRAINT nom_contrainte; ALTER TABLE nom_table MODIFY nomChamp type_champ;

Exercices d’interrogation — base LOCaFLOT

Les exercices suivants proviennent des séries SQL et de leurs corrections dans le Drive.

Filtres

  • Afficher les embarcations bleues, blanches et rouges.
  • Afficher les embarcations dont le numéro est compris entre J101 et P110.
  • Afficher les types d’embarcation dont le prix horaire est inconnu.
  • Afficher les types dont le nom commence par « b ».

Jointures

  • Afficher, pour chaque embarcation, son numéro, sa couleur et le nom de son type.
  • Afficher les embarcations de la location n° 7 avec leur couleur et leur type.
  • Afficher chaque location avec sa date, son embarcation et le nom du type, puis trier sur le numéro d’embarcation.

Fonctions de groupe

  • Compter les embarcations jaunes.
  • Calculer le prix horaire moyen.
  • Afficher le prix horaire minimal et maximal.
  • Compter les embarcations par couleur ou par type.
Exemples corrigés
-- Couleurs : appartenance à une liste SELECT * FROM EMBARCATION WHERE Couleur IN ('bleu','blanc','rouge'); -- Intervalle SELECT * FROM EMBARCATION WHERE Numembarcation BETWEEN 'J101'AND 'P110'; -- Valeur inconnue SELECT * FROM TYPEMBARCATION WHERE PrixH IS NULL; -- Nom commençant par b SELECT * FROM TYPEMBARCATION WHERE Nomtype LIKE 'b%';
-- Jointure embarcation / type SELECT Numembarcation, Couleur, Nomtype FROM EMBARCATION, TYPEMBARCATION WHERE EMBARCATION.Codetype = TYPEMBARCATION.Codetype;
-- Compter les embarcations jaunes SELECT COUNT(*) AS nb_emb_jaunes FROM EMBARCATION WHERE Couleur = 'jaune'; -- Prix horaire moyen SELECT AVG(PrixH) AS prixHoraireMoyen FROM TYPEMBARCATION; -- Minimum et maximum SELECT MIN(PrixH) AS prixMin, MAX(PrixH) AS prixMax FROM TYPEMBARCATION; -- Nombre par couleur SELECT Couleur, COUNT(*) FROM EMBARCATION GROUP BY Couleur;

Autres notions SQL de 1re année

LIMIT

La syntaxe SQL utilise LIMIT pour limiter le nombre de lignes retournées.

SELECT * FROM Employes LIMIT 5;

Alias

AS permet de donner un nom lisible à un résultat calculé, notamment avec les fonctions de groupe.

SELECT COUNT(*) AS NbEmbarcations FROM EMBARCATION;

Ordre de construction

Commencez par identifier les tables, choisissez les colonnes à afficher, ajoutez les critères, puis le regroupement ou le tri si nécessaire.

À maîtriser : reconnaître la famille de commande demandée, construire le prédicat, relier correctement les tables et vérifier l'effet d'une commande de modification avant son exécution.
