Bases numériques

Binaire

Base 2 : 0 et 1. 1 octet = 8 bits. Un quartet = 4 bits.

Décimal

Base 10 : système usuel.

Hexadécimal

Base 16 : 0–9 puis A–F. Un chiffre hexadécimal correspond à 4 bits.

1010₂ = 1×2³ + 0×2² + 1×2¹ + 0×2⁰ = 10₁₀ 0xFF = 15×16 + 15 = 255₁₀ 13₁₀ = 1101₂
Conversions : décimal → binaire par divisions successives par 2 ; binaire → décimal par somme des puissances de 2 ; binaire ↔ hexadécimal par groupes de 4 bits.

NOT

Inverse une valeur : NOT 0 = 1, NOT 1 = 0.

De Morgan

NOT(A AND B) = NOT(A) OR NOT(B)
NOT(A OR B) = NOT(A) AND NOT(B)

Algorithmique

Séquence

Instructions exécutées dans l’ordre.

Condition

SI / SINON pour choisir un traitement.

Boucles

POUR lorsque le nombre d’itérations est connu ; TANT QUE lorsque l’arrêt dépend d’une condition.

Fonction

Retourne une valeur ; une procédure réalise une action sans valeur de retour.

ALGORITHME Maximum(T, n) max ← T[0] POUR i ← 1 JUSQU'À n-1 SI T[i] > max ALORS max ← T[i] FIN POUR RETOURNER max
Récursivité : une fonction récursive doit toujours comporter un cas de base et un appel qui se rapproche de ce cas.
