INTRODUCTION
C'est quoi MS-DOS ?

Définition

MicroSoft Disk Operating System — créé en 1981 par Microsoft pour l'IBM PC. Mono-tâche, mono-utilisateur. Version finale : 6.22

Rôle du DOS

  • Gestion fichiers & répertoires
  • Gestion mémoires de stockage
  • Exécution de programmes
  • Configuration du matériel
  • Gestion entrées / sorties

Les 3 composantes

  • IO.SYS — lien BIOS ↔ DOS
  • MSDOS.SYS — routines disques
  • COMMAND.COM — interpréteur de commandes

Types de commandes

Internes Stockées dans COMMAND.COM (DIR, CD, MD…)
Externes Fichiers .EXE/.COM indépendants
Utilitaires DEFRAG, SCANDISK, FORMAT…

Structure fichiers & répertoires

Format 8.3

Nom : 8 car. max   Extension : 3 car. max
Séparés par un . — pas d'espace autorisé
Ex: SIO1DOSCDE.xls → SIO1DO~1.xls

Extensions courantes

  • .COM — commandes exécutables
  • .EXE — programmes exécutables
  • .BAT — fichier batch (lot de commandes)
  • .SYS — fichier système
  • .TXT — fichier texte ASCII

Attributs de fichier

  • r Lecture seule (read-only)
  • h Caché (hidden)
  • s Système (system)
  • a Archive (sauvegardé)

Méta-caractères

* Remplace n'importe quelle chaîne de caractères

? Remplace exactement un seul caractère

Exemples : *.txt   ???.doc   SIO*

FICHIERS .BAT
"

Un fichier BATCH (.bat) est un programme texte exécuté ligne par ligne par COMMAND.COM. Il automatise des tâches répétitives.
Appel : Nom_Fichier.BAT [P1] [P2]…[Pn]

Paramètres formels

Les %n (paramètres)

  • %0 nom du fichier batch lui-même
  • %1 1er paramètre réel passé
  • %2 2e paramètre réel passé
  • %n nième paramètre (max 9, puis utiliser SHIFT)

Exemple d'appel

# affiche.bat contient : ECHO %2 ECHO %1 # Appel : C:\> affiche rouge noir # Résultat affiché : noir # rouge
Instructions spécifiques .BAT
InstructionRôle
@ECHO OFFMasque l'affichage des commandes + masque lui-même (grâce au @)
ECHO <msg>Affiche un message à l'écran
REMLigne de commentaire (visible seulement si ECHO ON)
PAUSESuspend l'exécution — "Appuyez sur une touche pour continuer…"
GOTO :LABELSaut inconditionnel vers une étiquette (1–8 caractères)
IF [NOT] cond cmdExécution conditionnelle d'une commande
FOR %%v IN (jeu) DOBoucle sur un ensemble de fichiers ou valeurs
CALLAppelle un autre fichier batch (et y revient)
SHIFTDécale les paramètres : %1→%0, %2→%1, etc.
REM ===== trouve.bat : vérifie si un fichier existe ===== IF NOT EXIST %1 GOTO :erreur ECHO Ce fichier est présent ! GOTO :fin :erreur ECHO Ce fichier est introuvable ! :fin REM ===== FOR : affiche tous les .txt et .pdf ===== FOR %1 IN (*.pdf *.txt) DO type %1 REM Opérateurs de comparaison utilisables dans IF : REM EQU (égal) NEQ (différent) LSS (strictement inférieur) REM GTR (strictement supérieur) GEQ (supérieur ou égal) LEQ (inférieur ou égal) REM == (égalité chaînes) EXIST (fichier existe)
💡 Astuce : Toujours commencer un .bat par @ECHO OFF pour un affichage propre. Utiliser CLS pour effacer l'écran.
